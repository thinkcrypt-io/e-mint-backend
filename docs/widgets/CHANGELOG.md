## W-02 — Countries (2026-10-05)
- **The user's words:** "when creating organization should select country,
  Country list should be there and they can search. List all the countries and
  their map images, phone extensions on a db. start with bangladesh and 10
  countries we'll seed later, if the organization is bangladeshi then
  sslcommerz, bkash should be there too. otherwise stripe."
- **Model** `library/models/tenancy/country.model.ts` (global `countries`):
  code, code3, name, nativeName, dialCode, flag emoji, `flagSvg` / `mapSvg`
  (in the database, `select: false`), currency, region, `paymentProviders`
  (stripe, sslcommerz, bkash), active, priority.
- **Data** `library/data/countries.ts` — Bangladesh (priority 100; SSLCommerz,
  bKash, Stripe), India, Pakistan, United States, United Kingdom, UAE, Saudi
  Arabia, Malaysia, Singapore, Canada, Australia (Stripe).
  `library/data/countryAssets.ts` generated by
  `scripts/countries/buildCountryAssets.mjs`: flags from flag-icons (MIT, via
  flagcdn.com), map outlines drawn from Natural Earth (public domain; 1:50m,
  Singapore from 1:10m).
- **Functions** `library/functions/countries.function.ts`: `seedCountries` at
  boot (adds missing countries, fills missing pictures, keeps edits; then gives
  old organizations their country where the sign-up answer names one),
  `listCountries` (5-minute cache), `countryByCode`, `providersFor`,
  `countryPicture`.
- **Public** `routes-public/index.ts`: `GET /public/countries` (with `flagUrl`,
  `mapUrl`), `/public/countries/:code`, `/:code/flag.svg`, `/:code/map.svg`
  (image/svg+xml, a day's cache, `default-src 'none'`).
- **Organizations**: `Organization.country`; `checkCountry` (tenancy.function)
  refuses codes not in the list (`country_unknown`); required on
  `POST /tenant/api/auth/register` and `POST /tenant/api/org`, changeable with
  `PUT /tenant/api/org`; `publicOrganization` adds `country` and
  `paymentProviders`.
- **Panel** (admin): `components/library/tenant/CountrySelect.tsx` (Chakra
  Combobox; search by name, native name, code or dial code; flags) on sign-up
  (step 1, required — the old free-text country left step 2), New organization
  and organization settings (with the providers on offer); `tenantApi` types;
  user guides (getting started, organizations).
- Verified: smoke `countries.mjs` (15 checks; added to run-all) and the suites
  that sign up organizations (tenant-auth, org-1, projects, access, activity —
  their sign-ups now send a country); in the browser: sign-up with the picker
  (search by name and +44), settings show Bangladesh with SSLCommerz, bKash,
  Stripe, change and save, New organization in the UK → Stripe; the backfill
  on a fake old organization ("bangladesh" → BD, "Narnia" left alone).
